# Liga de Básquetbol

Aplicación web para gestionar una liga de básquetbol: usuarios, equipos, jugadores, partidos y estadísticas.

## Tecnologías

- PHP 8.2 o superior y Laravel 12
- MySQL / MariaDB
- Git y GitHub

## Instalación

1. Clonar el repositorio e ingresar a la carpeta.
2. `composer install`
3. Copiar `.env.example` a `.env` y ejecutar `php artisan key:generate`
4. Crear la base de datos `basquetbol` en MySQL.
5. `php artisan migrate`
6. `php artisan serve` y abrir http://127.0.0.1:8000
